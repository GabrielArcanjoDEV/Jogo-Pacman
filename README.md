## 📝 Descrição
Jogo inspirado no clássico Pac-Man, desenvolvido para praticar lógica de programação, movimentação de personagens e interação em tempo real em um labirinto cheio de desafios.

## 🎮 Destaques do Projeto
- Implementação de lógica de movimentação.
- Interação dinâmica entre personagens e cenário.
- Desafios clássicos de labirinto.

## 🛠️ Tecnologias Utilizadas
- **JavaScript (ES6+)**
- **HTML5 & CSS3**

## 🕹️ Como Jogar
1. Abra o arquivo `index.html` no seu navegador.
2. Divirta-se explorando o labirinto e testando a lógica do jogo!
